# SurvStats

Companion apps for the book **Statistics Surveyors and Geomaticians Should Know: Plain-Language Statistics with Worked Examples and Apps** by Yam Khoon Tor.

## Use online

https://yamkhoontor.github.io/SurvStats/

## Use offline

1. Click **Code → Download ZIP** on this page.
2. Unzip the folder anywhere on your computer.
3. Double-click `index.html`. It opens in your web browser. No installation or internet connection is needed.

## The seven apps

| App | Book chapters | What it does |
|---|---|---|
| Descriptive statistics | 3, 4 | Mean, median, standard deviation, standard error, confidence interval, outlier flags, dot plot |
| Uncertainty propagation | 5, 6 | EDM specification, levelling run, trigonometric height, rectangle area, build-your-own uncertainty budget |
| Error ellipse | 8 | Standard and 90/95/99% ellipses, bearing, DRMS, 2DRMS, CEP |
| Hypothesis tests | 9, 11 | t-test, chi-square global test, F-test, plan and height displacement tests |
| Trend fit | 12 | Straight-line fit, rate with confidence interval, R², residual plot, prediction band, time to Alert Level |
| Accuracy assessment | 13 | Bias, standard deviation, RMSE, median, NMAD, percentiles, NSSDA and LE90 values, histogram |
| Control chart | 14 | Shewhart chart with warning and action limits and four out-of-control rules |

Each app opens with the data of the book's worked example, so you can check the results against the book and then type in your own numbers. You can open an app directly by adding its name to the address, for example `index.html#trend`.

## Publishing on GitHub Pages

1. Create a public repository named `SurvStats` under the account `yamkhoontor`.
2. Upload `index.html` and this `README.md`.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the apps are live at https://yamkhoontor.github.io/SurvStats/
